# Sketch: Multilevel Refinement Theorem

## The Claim

**Theorem:** Let $g : \mathcal{D} \to \mathcal{D}$ be a multilevel function defined by a Boolean DSGRN parameter $(\hat{f}, \theta)$ corresponding to a Boolean model $f : \mathbb{B}^N \to \mathbb{B}^N$. Then $g$ is a multilevel refinement of $f$.

## Definition of Refinement

A multilevel function $g$ is a **multilevel refinement** of Boolean model $f$ if for the labeling $\alpha$ generated by $g$, for every $(d, j, \pm 1) \in \Omega$ and every $i \in \{1, \ldots, N\}$:

(i) If $\alpha(d, j, \pm 1) = 1$, then **there exists** $b \in M(d)$ such that $f_i(b) = 1$

(ii) If $\alpha(d, j, \pm 1) = -1$, then **there exists** $b \in M(d)$ such that $f_i(b) = 0$

## Key Observation

The definition says "**there exists**" a binarization, not "for all" binarizations. This is crucial!

For a multilevel state $d \in \mathcal{D}$, the set $M(d)$ contains **all possible** ways to map $d$ to a Boolean state $b \in \mathbb{B}^N$ while respecting the monotonicity and boundary conditions:
- $\mu_i(0) = 0$ and $\mu_i(m_i) = 1$ for all $i$
- $\mu_i$ is monotone increasing

So if $d_i \in \{1, \ldots, m_i - 1\}$ (intermediate level), then $\mu_i(d_i)$ can be either $0$ or $1$.

## Example: Why "There Exists" Matters

Consider $d = (1, 1) \in \mathcal{D} = \{0,1,2\} \times \{0,1\}$ for a two-node network.

The set $M(d)$ contains:
- $b_1 = (0, 1)$ via binarization $\mu_1(1) = 0, \mu_2(1) = 1$
- $b_2 = (1, 1)$ via binarization $\mu_1(1) = 1, \mu_2(1) = 1$

If $\alpha(d, 1, +1) = 1$ (flow in direction 1 is positive), we need to show there exists **some** $b \in M(d)$ with $f_1(b) = 1$.

We don't need $f_1(b) = 1$ for **all** $b \in M(d)$. Just one is enough!

## Proof Strategy

For a Boolean parameter $(\hat{f}, \theta)$, we have $f_i^j = \tilde{f}_i$ for all $j$ (all edges from node $i$ use the same function).

This means:
$$g_i(d) = \sum_{j \in \text{Targets}(i)} f_i^j(B^i(d)) = \sum_{j \in \text{Targets}(i)} \tilde{f}_i(B^i(d)) = m_i \cdot \tilde{f}_i(B^i(d))$$

So $g_i(d) \in \{0, m_i\}$ only (either all edges turn on or none do).

### Case 1: $\alpha(d, i, \pm 1) = 1$

This means $g_i(d) \geq d_i$ (with appropriate sign).

Since $g_i(d) = m_i \cdot \tilde{f}_i(B^i(d))$:
- If $\tilde{f}_i(B^i(d)) = 1$, then $g_i(d) = m_i$
- If $\tilde{f}_i(B^i(d)) = 0$, then $g_i(d) = 0$

If $\alpha(d, i, \pm 1) = 1$ and we're checking $f_i$, we need to find $b \in M(d)$ with $f_i(b) = 1$.

**Key construction:** Define binarization $\mu$ by:
$$\mu_k(d_k) := \tilde{f}_k(B^k(d))$$

This gives $b = \mu(d)$ satisfying:
- $b \in M(d)$ (need to verify monotonicity and boundary conditions)
- $f_i(b) = f_i(\mu(d))$ relates to $\tilde{f}_i(B^i(d))$ through the encoding

Since $B$ encodes the edge signs and $f$ is related to $\tilde{f}$ via change of variables $\beta$, we have:
$$f_i(B(d)) = \tilde{f}_i(B^i(d))$$

Wait, this needs more care because $B : \mathcal{D} \to \mathbb{B}^{|E|}$ but $f$ expects $\mathbb{B}^N$ as input...

## The Right Approach

The key is that for Boolean parameter:
$$g_i(d) = m_i \cdot \tilde{f}_i(B^i(d))$$

And we can construct a specific binarization $\mu$ such that:
$$\mu_k(d_k) = b_k^{\ell}(d)$$

for some choice of target edge $\ell \in \text{Targets}(k)$.

Then the encoding function $B$ evaluated on this binarized state gives:
$$f_k(b) = f_k(\mu(d))$$

which relates to $\tilde{f}_k(B^k(d))$ through the change of variables.

The "there exists" is crucial because we only need to find **one** consistent binarization, not prove it for all possible binarizations.

## What Needs to Be Shown

1. For Boolean parameter $(\hat{f}, \theta)$ with $f_i^j = \tilde{f}_i$ for all $j$:
   - Construct explicit binarization $\mu : \mathcal{D} \to \mathbb{B}^N$
   - Verify $\mu(d) \in M(d)$ (monotone, satisfies boundaries)
   - Show $f_i(\mu(d))$ matches the sign of $\alpha(d, i, \pm 1)$

2. The construction likely uses:
   - $\mu_i(d_i) = 1$ if $d_i > 0$, else $\mu_i(d_i) = 0$
   - Or: $\mu_i(d_i) = 1$ if $d_i = m_i$, else $\mu_i(d_i) = 0$
   - Or: Something more subtle based on $B^i(d)$

3. Key commutative property:
   $$f(B(d)) = f(\mu(d))$$
   for the specific choice of $\mu$.

## Questions

1. What is the explicit construction of the binarization $\mu$?
2. Does it use $\mu_i(d_i) = \mathbb{1}_{d_i > 0}$ or $\mu_i(d_i) = \mathbb{1}_{d_i = m_i}$?
3. How does the encoding function $B : \mathcal{D} \to \mathbb{B}^{|E|}$ relate to the Boolean input $\mathbb{B}^N$?

The "there exists" formulation makes the theorem weaker (easier to prove) than "for all", which is exactly what's needed since multilevel states can have multiple Boolean interpretations.
